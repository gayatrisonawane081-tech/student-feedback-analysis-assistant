# Student Feedback Analysis Assistant

An AI-powered web application that analyzes student feedback using Python and sentiment analysis.

## Features
- Analyze student feedback.
- Identify positive, negative, and neutral sentiment.
- Detect topics such as teaching, course content, infrastructure, assessment, and student support.
- Provide suggestions based on feedback.
- View feedback statistics on a dashboard.

## Technologies Used
- Python
- Flask
- VADER Sentiment Analysis
- HTML
- CSS

## Installation and Setup

1. Clone this repository:
   `git clone YOUR_REPOSITORY_URL`

2. Open the project folder:
   `cd StudentFeedbackAgent`

3. Install the required packages:
   `pip install -r requirements.txt`

4. Run the application:
   `python app.py`

5. Open this URL in your browser:
   `http://127.0.0.1:5000`
